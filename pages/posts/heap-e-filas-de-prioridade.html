Heap e filas de prioridade: quando a ordem importa

Vimos que uma fila comum segue FIFO. Mas e se a ordem não for "quem chegou primeiro", e sim "quem é mais urgente"? É aí que entram as filas de prioridade, implementadas com uma estrutura chamada Heap.

O que é um Heap?

Um heap é uma árvore binária especial que obedece a uma regra:

  • Max-Heap: cada nó pai é maior ou igual aos seus filhos. O maior valor está sempre na raiz.
  • Min-Heap: cada nó pai é menor ou igual aos seus filhos. O menor valor está sempre na raiz.
// Min-Heap visual:
//        5
//      /   \
//     10    15
//    /  \  /
//   20  25 30
//
// Max-Heap visual:
//        30
//      /    \
//     25     20
//    /  \   /
//   15  10 5

PriorityQueue no Java

O Java implementa fila de prioridade com um min-heap (o menor elemento sai primeiro). 

PriorityQueue<Integer> pq = new PriorityQueue<>();

pq.offer(30);
pq.offer(10);
pq.offer(20);
pq.offer(5);

System.out.println(pq.poll()); // 5 (menor)
System.out.println(pq.poll()); // 10
System.out.println(pq.poll()); // 20
System.out.println(pq.poll()); // 30

Para inverter a ordem (max-heap), use um Comparator: 

PriorityQueue<Integer> maxPq = new PriorityQueue<>(Comparator.reverseOrder());

maxPq.offer(10);
maxPq.offer(30);
maxPq.offer(20);

System.out.println(maxPq.poll()); // 30 (maior)

Como o heap funciona por dentro

Diferente de uma árvore comum, o heap é geralmente implementado com um array. Para um elemento no índice i:

  • Filho esquerdo: 2 * i + 1
  • Filho direito: 2 * i + 2
  • Pai: (i - 1) / 2
// Array: [5, 10, 15, 20, 25, 30]
//                  5 (i=0)
//                /   \
//           10 (i=1) 15 (i=2)
//           /    \    /
//     20 (i=3) 25(i=4) 30(i=5)

// O heap nunca está totalmente ordenado, mas a raiz sempre é a menor/maior.

Inserção (offer)

Adiciona no fim do array e "sobe" o elemento trocando com o pai até a regra do heap ser satisfeita. O(log n).

Remoção (poll)

Remove a raiz (primeiro elemento), coloca o último elemento na raiz e "desce" trocando com o menor filho (min-heap). O(log n).

Onde filas de prioridade aparecem

  • Escalonamento de processos: o sistema operacional decide qual processo executar primeiro com base na prioridade.
  • Dijkstra (menor caminho): usa uma fila de prioridade para sempre expandir o nó mais próximo.
  • Merge de K listas ordenadas: insere o primeiro elemento de cada lista e sempre extrai o menor.
  • Top K elementos: encontrar os K maiores/menores elementos de uma coleção enorme.
  • Hospitais/emergências: pacientes são triados por gravidade, não por ordem de chegada.

Exemplo: Top K maiores elementos

// Encontrar os 3 maiores números de um array
int[] numeros = {3, 7, 1, 9, 4, 8, 2, 6, 5};
int k = 3;

PriorityQueue<Integer> minHeap = new PriorityQueue<>();
for (int n : numeros) {
    minHeap.offer(n);
    if (minHeap.size() > k) {
        minHeap.poll(); // remove o menor, mantém os K maiores
    }
}

System.out.println(minHeap); // [7, 8, 9] (os 3 maiores)
Exercícios

1. Késimo menor elemento

Dado um array, encontre o K-ésimo menor elemento usando um max-heap.

Mostrar sugestão 
int kEsimoMenor(int[] nums, int k) {
    PriorityQueue<Integer> maxHeap = new PriorityQueue<>(Comparator.reverseOrder());
    for (int n : nums) {
        maxHeap.offer(n);
        if (maxHeap.size() > k) maxHeap.poll();
    }
    return maxHeap.peek();
}

2. Mediana dinâmica

Implemente uma estrutura que recebe números um por um e consegue retornar a mediana a qualquer momento. Dica: use dois heaps (um max e um min).

3. (Desafio) Quase-ordenado

Um array está "quase ordenado": cada elemento está a no máximo K posições de sua posição correta. Ordene-o eficientemente usando um heap.

O heap é uma das estruturas mais engenhosas: combina a simplicidade do array com a lógica da árvore para resolver problemas de prioridade de forma elegante.

We saw that a regular queue follows FIFO. But what if the order is not "who arrived first", but "who is most urgent"? That is where priority queues come in, implemented with a structure called a Heap.

What is a Heap?

A heap is a special binary tree that follows a rule:

  • Max-Heap: each parent node is greater than or equal to its children. The largest value is always at the root.
  • Min-Heap: each parent node is less than or equal to its children. The smallest value is always at the root.
// Min-Heap visual:
//        5
//      /   //     10    15
//    /  \  /
//   20  25 30
//
// Max-Heap visual:
//        30
//      /    //     25     20
//    /  \   /
//   15  10 5

PriorityQueue in Java

Java implements priority queue with a min-heap (smallest element comes out first). 

PriorityQueue<Integer> pq = new PriorityQueue<>();

pq.offer(30);
pq.offer(10);
pq.offer(20);
pq.offer(5);

System.out.println(pq.poll()); // 5 (smallest)
System.out.println(pq.poll()); // 10
System.out.println(pq.poll()); // 20
System.out.println(pq.poll()); // 30

To reverse the order (max-heap), use a Comparator: 

PriorityQueue<Integer> maxPq = new PriorityQueue<>(Comparator.reverseOrder());

maxPq.offer(10);
maxPq.offer(30);
maxPq.offer(20);

System.out.println(maxPq.poll()); // 30 (largest)

How heap works under the hood

Unlike a regular tree, a heap is usually implemented with an array. For an element at index i:

  • Left child: 2 * i + 1
  • Right child: 2 * i + 2
  • Parent: (i - 1) / 2
// Array: [5, 10, 15, 20, 25, 30]
//                  5 (i=0)
//                /   //           10 (i=1) 15 (i=2)
//           /    \    /
//     20 (i=3) 25(i=4) 30(i=5)

// The heap is never fully sorted, but the root is always the smallest/largest.

Insertion (offer)

Adds at the end of the array and "bubbles up" by swapping with the parent until the heap rule is satisfied. O(log n).

Removal (poll)

Removes the root (first element), puts the last element at the root, and "bubbles down" by swapping with the smallest child (min-heap). O(log n).

Where priority queues appear

  • Process scheduling: the OS decides which process runs next based on priority.
  • Dijkstra (shortest path): uses a priority queue to always expand the closest node.
  • Merge K sorted lists: inserts the first element of each list and always extracts the smallest.
  • Top K elements: finding the K largest/smallest elements from a huge collection.
  • Hospitals/emergency rooms: patients are triaged by severity, not arrival order.

Example: Top K largest elements

// Find the 3 largest numbers from an array
int[] numbers = {3, 7, 1, 9, 4, 8, 2, 6, 5};
int k = 3;

PriorityQueue<Integer> minHeap = new PriorityQueue<>();
for (int n : numbers) {
    minHeap.offer(n);
    if (minHeap.size() > k) {
        minHeap.poll(); // removes the smallest, keeps the K largest
    }
}

System.out.println(minHeap); // [7, 8, 9] (the 3 largest)

2. Dynamic median

Implement a structure that receives numbers one by one and can return the median at any time. Hint: use two heaps (one max, one min).

3. (Challenge) Nearly sorted

An array is "nearly sorted": each element is at most K positions away from its correct position. Sort it efficiently using a heap.

The heap is one of the most ingenious structures: it combines the simplicity of an array with the logic of a tree to solve priority problems elegantly.
