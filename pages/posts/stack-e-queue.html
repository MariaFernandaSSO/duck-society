Duck To Basics

Stack e Queue: a base de muita coisa que você já usa

Vimos que a LinkedList pode ser usada como fila. Mas o que exatamente são pilhas (stacks) e filas (queues)? São duas estruturas de dados tão simples quanto poderosas, e você usa ambas diariamente sem perceber.

Stack (Pilha) - LIFO

LIFO = Last In, First Out. O último que entra é o primeiro que sai.

Pense numa pilha de pratos: você coloca um em cima do outro, e quando vai tirar, tira o de cima primeiro. 

// Operações principais:
// push(item)  - coloca no topo
// pop()       - remove do topo e retorna
// peek()      - olha o topo sem remover
// empty()     - verifica se está vazia

Stack<String> pilha = new Stack<>();
pilha.push("A");
pilha.push("B");
pilha.push("C");

System.out.println(pilha.pop());  // C
System.out.println(pilha.peek()); // B
System.out.println(pilha.pop());  // B
System.out.println(pilha.pop());  // A

Onde stacks aparecem

  • Botão "voltar" do navegador: cada página que você visita é empilhada. O "voltar" desempilha.
  • Ctrl+Z (undo): cada ação é empilhada. Desfazer = desempilhar.
  • Call stack da sua linguagem: quando uma função chama outra, o contexto é empilhado.
  • Editor de código: validação de chaves { } usa stack - abre empilha, fecha desempilha.

Validando parênteses com Stack

boolean ehValido(String s) {
    Stack<Character> pilha = new Stack<>();
    for (char c : s.toCharArray()) {
        if (c == '(' || c == '[' || c == '{') {
            pilha.push(c);
        } else {
            if (pilha.isEmpty()) return false;
            char topo = pilha.pop();
            if ((c == ')' && topo != '(') ||
                (c == ']' && topo != '[') ||
                (c == '}' && topo != '{')) {
                return false;
            }
        }
    }
    return pilha.isEmpty();
}

System.out.println(ehValido("({[]})")); // true
System.out.println(ehValido("({[})"));  // false

Queue (Fila) - FIFO

FIFO = First In, First Out. O primeiro que entra é o primeiro que sai.

Pense numa fila de banco: quem chega primeiro é atendido primeiro. 

// Operações principais:
// offer(item)  - adiciona no fim
// poll()       - remove do início e retorna
// peek()       - olha o início sem remover

Queue<String> fila = new LinkedList<>();
fila.offer("A");
fila.offer("B");
fila.offer("C");

System.out.println(fila.poll());  // A
System.out.println(fila.peek()); // B
System.out.println(fila.poll());  // B
System.out.println(fila.poll());  // C

Onde queues aparecem

  • Filas de impressão: documentos são impressos na ordem de chegada.
  • Message brokers: RabbitMQ, Kafka, SQS - filas são a base da comunicação assíncrona.
  • Thread pools: tarefas aguardam numa fila até serem executadas.
  • BFS (Breadth-First Search): o algoritmo de busca em largura usa uma fila.

Stack vs Queue - resumo

Característica Stack Queue
Princípio LIFO (último a entrar, primeiro a sair) FIFO (primeiro a entrar, primeiro a sair)
Inserção push() - no topo offer() - no fim
Remoção pop() - do topo poll() - do início
Uso típico Undo, call stack, validação de sintaxe Filas de processamento, BFS, buffers
Exercícios

1. Fila com duas stacks

Implemente uma fila usando duas stacks. A ideia é clássica em entrevistas: uma stack para enfileirar, outra para desenfileirar.

Mostrar sugestão 
class FilaComStacks<T> {
    Stack<T> entrada = new Stack<>();
    Stack<T> saida = new Stack<>();

    void enfileirar(T item) { entrada.push(item); }

    T desenfileirar() {
        if (saida.isEmpty()) {
            while (!entrada.isEmpty()) {
                saida.push(entrada.pop());
            }
        }
        return saida.pop();
    }
}

2. Palíndromo com Stack

Use uma stack para verificar se uma palavra é um palíndromo (lê-se igual de trás pra frente).

3. (Desafio) Fila circular

Implemente uma fila circular com capacidade fixa usando um array. Quando o fim do array é atingido, volta ao início.

We saw that LinkedList can be used as a queue. But what exactly are stacks and queues? They are two data structures as simple as they are powerful, and you use both daily without realizing it.

Stack - LIFO

LIFO = Last In, First Out. The last one in is the first one out.

Think of a stack of plates: you put one on top of another, and when you take one, you take the top one first. 

// Main operations:
// push(item)  - puts on top
// pop()       - removes from top and returns
// peek()      - looks at the top without removing
// empty()     - checks if empty

Stack<String> stack = new Stack<>();
stack.push("A");
stack.push("B");
stack.push("C");

System.out.println(stack.pop());  // C
System.out.println(stack.peek()); // B
System.out.println(stack.pop());  // B
System.out.println(stack.pop());  // A

Where stacks appear

  • Browser back button: each page you visit is stacked. The "back" button pops.
  • Ctrl+Z (undo): each action is stacked. Undo = pop.
  • Call stack: when a function calls another, the context is stacked.
  • Code editor: brace validation { } uses a stack - open pushes, close pops.

Validating parentheses with Stack

boolean isValid(String s) {
    Stack<Character> stack = new Stack<>();
    for (char c : s.toCharArray()) {
        if (c == '(' || c == '[' || c == '{') {
            stack.push(c);
        } else {
            if (stack.isEmpty()) return false;
            char top = stack.pop();
            if ((c == ')' && top != '(') ||
                (c == ']' && top != '[') ||
                (c == '}' && top != '{')) {
                return false;
            }
        }
    }
    return stack.isEmpty();
}

System.out.println(isValid("({[]})")); // true
System.out.println(isValid("({[})"));  // false

Queue - FIFO

FIFO = First In, First Out. The first one in is the first one out.

Think of a bank queue: whoever arrives first gets served first. 

// Main operations:
// offer(item)  - adds at the end
// poll()       - removes from the front and returns
// peek()       - looks at the front without removing

Queue<String> queue = new LinkedList<>();
queue.offer("A");
queue.offer("B");
queue.offer("C");

System.out.println(queue.poll());  // A
System.out.println(queue.peek()); // B
System.out.println(queue.poll());  // B
System.out.println(queue.poll());  // C

Where queues appear

  • Print queues: documents are printed in order of arrival.
  • Message brokers: RabbitMQ, Kafka, SQS - queues are the foundation of async communication.
  • Thread pools: tasks wait in a queue until executed.
  • BFS (Breadth-First Search): the graph traversal algorithm uses a queue.

Stack vs Queue - summary

Feature Stack Queue
Principle LIFO (last in, first out) FIFO (first in, first out)
Insertion push() - on top offer() - at the end
Removal pop() - from the top poll() - from the front
Typical use Undo, call stack, syntax validation Processing queues, BFS, buffers
Exercises

1. Queue with two stacks

Implement a queue using two stacks. This is a classic interview problem: one stack for enqueueing, another for dequeueing.

Show solution 
class QueueWithStacks<T> {
    Stack<T> input = new Stack<>();
    Stack<T> output = new Stack<>();

    void enqueue(T item) { input.push(item); }

    T dequeue() {
        if (output.isEmpty()) {
            while (!input.isEmpty()) {
                output.push(input.pop());
            }
        }
        return output.pop();
    }
}

2. Palindrome with Stack

Use a stack to check if a word is a palindrome (reads the same backwards).

3. (Challenge) Circular queue

Implement a circular queue with fixed capacity using an array. When the end of the array is reached, it wraps around to the beginning.
