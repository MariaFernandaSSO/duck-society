Árvores: o que são e onde aparecem sem você perceber

Vimos listas, pilhas, filas e mapas - estruturas lineares. Agora é hora de subir um nível: árvores são estruturas hierárquicas que organizam o mundo digital.

O que é uma árvore?

Uma árvore é uma estrutura de dados composta por nós conectados por arestas. Cada nó tem um nó pai (exceto a raiz) e zero ou mais nós filhos. 

// Estrutura visual:
//         (raiz)
//        /   |   \
//    filho filho filho
//      / \
//  neto neto

class No {
    int valor;
    No[] filhos; // ou List<No> filhos
}

Árvore Binária

O tipo mais comum de árvore: cada nó tem no máximo dois filhos - esquerda e direita. 

class NoBinario {
    int valor;
    NoBinario esquerda;
    NoBinario direita;

    NoBinario(int valor) { this.valor = valor; }
}

// Visual:
//     10
//    /  \
//   5    15
//  / \     \
// 3   7     20

Árvore Binária de Busca (BST)

Uma BST é uma árvore binária com uma regra extra: o filho da esquerda é menor que o pai, e o filho da direita é maior. Isso permite busca eficiente. 

class BST {
    NoBinario raiz;

    void inserir(int valor) {
        raiz = inserirRec(raiz, valor);
    }

    private NoBinario inserirRec(NoBinario no, int valor) {
        if (no == null) return new NoBinario(valor);
        if (valor < no.valor)
            no.esquerda = inserirRec(no.esquerda, valor);
        else if (valor > no.valor)
            no.direita = inserirRec(no.direita, valor);
        return no;
    }

    boolean buscar(int valor) {
        return buscarRec(raiz, valor);
    }

    private boolean buscarRec(NoBinario no, int valor) {
        if (no == null) return false;
        if (valor == no.valor) return true;
        return valor < no.valor
            ? buscarRec(no.esquerda, valor)
            : buscarRec(no.direita, valor);
    }
}

// Busca em BST é O(log n) na média - muito mais rápido que lista O(n)

Percorrendo uma árvore

In-order (esquerda → raiz → direita): retorna os elementos em ordem crescente numa BST.

void emOrdem(NoBinario no) {
    if (no == null) return;
    emOrdem(no.esquerda);
    System.out.print(no.valor + " ");
    emOrdem(no.direita);
}

// Na árvore acima: 3 5 7 10 15 20

Pre-order (raiz → esquerda → direita): útil para copiar a árvore.

Post-order (esquerda → direita → raiz): útil para deletar a árvore.

Onde árvores aparecem

  • Sistema de arquivos: pastas e arquivos formam uma árvore.
  • DOM do navegador: a estrutura HTML é uma árvore de elementos.
  • Bancos de dados: índices B-Tree são usados no MySQL, PostgreSQL, SQLite.
  • Compiladores: a AST (Abstract Syntax Tree) representa o código fonte.
  • Redes: roteamento usa árvores para decisões de caminho.
  • Algoritmos de compressão: Huffman coding usa árvore binária.

Árvores balanceadas

Uma BST pode degenerar numa lista se os dados forem inseridos em ordem. Para evitar isso, existem árvores que se autobalanceiam:

  • AVL: mantém a diferença de altura entre subárvores ≤ 1
  • Rubro-Negra (Red-Black): usada no TreeMap e TreeSet do Java
  • B-Tree: usada em bancos de dados (nós podem ter muitos filhos)
Exercícios

Mostrar sugestão

    while (no.esquerda != null) no = no.esquerda;
    return no.valor;
}

int maior(NoBinario no) {
    while (no.direita != null) no = no.direita;
    return no.valor;
}

Árvores são a porta de entrada para estruturas não-lineares. Elas estão em todo lugar - e quanto mais você entende delas, mais percebe o mundo digital organizado hierarquicamente.

We have seen lists, stacks, queues, and maps - linear structures. Now it is time to level up: trees are hierarchical structures that organize the digital world.

What is a tree?

A tree is a data structure made of nodes connected by edges. Each node has a parent (except the root) and zero or more children. 

// Visual structure:
//         (root)
//        /   |   //    child child child
//      / //  grandchild grandchild

class Node {
    int value;
    Node[] children; // or List<Node> children
}

Binary Tree

The most common type of tree: each node has at most two children - left and right. 

class BinaryNode {
    int value;
    BinaryNode left;
    BinaryNode right;

    BinaryNode(int value) { this.value = value; }
}

// Visual:
//     10
//    /  //   5    15
//  / \     // 3   7     20

Binary Search Tree (BST)

A BST is a binary tree with an extra rule: the left child is smaller than the parent, and the right child is greater. This enables efficient searching. 

class BST {
    BinaryNode root;

    void insert(int value) {
        root = insertRec(root, value);
    }

    private BinaryNode insertRec(BinaryNode node, int value) {
        if (node == null) return new BinaryNode(value);
        if (value < node.value)
            node.left = insertRec(node.left, value);
        else if (value > node.value)
            node.right = insertRec(node.right, value);
        return node;
    }

    boolean search(int value) {
        return searchRec(root, value);
    }

    private boolean searchRec(BinaryNode node, int value) {
        if (node == null) return false;
        if (value == node.value) return true;
        return value < node.value
            ? searchRec(node.left, value)
            : searchRec(node.right, value);
    }
}

// BST search is O(log n) on average - much faster than O(n) for a list

Traversing a tree

In-order (left -> root -> right): returns elements in ascending order in a BST.

void inOrder(BinaryNode node) {
    if (node == null) return;
    inOrder(node.left);
    System.out.print(node.value + " ");
    inOrder(node.right);
}

// On the tree above: 3 5 7 10 15 20

Pre-order (root -> left -> right): useful for copying the tree.

Post-order (left -> right -> root): useful for deleting the tree.

Where trees appear

  • File system: folders and files form a tree.
  • Browser DOM: the HTML structure is a tree of elements.
  • Databases: B-Tree indexes are used in MySQL, PostgreSQL, SQLite.
  • Compilers: the AST (Abstract Syntax Tree) represents source code.
  • Networks: routing uses trees for path decisions.
  • Compression algorithms: Huffman coding uses a binary tree.

Balanced trees

A BST can degenerate into a list if data is inserted in order. To prevent this, there are self-balancing trees:

  • AVL: maintains height difference between subtrees <= 1
  • Red-Black: used in Java TreeMap and TreeSet
  • B-Tree: used in databases (nodes can have many children)
Exercises

1. Min and max

Given a BST, implement methods to find the smallest and largest value.

Show solution 
int min(BinaryNode node) {
    while (node.left != null) node = node.left;
    return node.value;
}

int max(BinaryNode node) {
    while (node.right != null) node = node.right;
    return node.value;
}

2. Tree height

Implement a method that calculates the height (maximum depth) of a binary tree.

3. (Challenge) Validate BST

Given a binary tree, check if it is a valid BST (every left node is smaller, every right node is greater).

Trees are the gateway to non-linear structures. They are everywhere - and the more you understand them, the more you see the digital world organized hierarchically.
