Duck To Basics

Arrays: o começo de tudo

No post anterior, vimos o que são estruturas de dados. Agora vamos à primeira delas - e provavelmente a que você já usa mais sem perceber.

De todas as estruturas de dados, o array é a mais simples e a mais fundamental. Se você entender bem arrays, tudo que vier depois (listas, pilhas, filas, matrizes) fica mais fácil.

O que é um array?

Um array é uma coleção de elementos do mesmo tipo, armazenados em posições consecutivas de memória. Cada posição tem um índice (número) que começa em 0. 

// Visualmente:
//   [10] [20] [30] [40] [50]
//     0    1    2    3    4

int[] numeros = {10, 20, 30, 40, 50};
System.out.println(numeros[0]); // 10
System.out.println(numeros[2]); // 30
System.out.println(numeros[4]); // 50

Por que arrays existem?

Sem arrays, você precisaria de uma variável pra cada valor: 

int nota1 = 8;
int nota2 = 7;
int nota3 = 9;
int nota4 = 6;
int nota5 = 10;
// E se fossem 500 notas?

Com array, você agrupa tudo numa variável só e acessa pelo índice: 

int[] notas = {8, 7, 9, 6, 10};
System.out.println(notas[0]); // 8
System.out.println(notas.length); // 5

Declarando e inicializando

Java:

// Jeito 1: declarar e já inicializar
int[] idades = {18, 22, 25, 30};

// Jeito 2: declarar o tamanho e preencher depois
int[] salarios = new int[4];
salarios[0] = 2500;
salarios[1] = 3200;
salarios[2] = 4100;
salarios[3] = 3800;

// Jeito 3: com new e valores
int[] dados = new int[]{1, 2, 3, 4, 5};

Go:

// Jeito 1
idades := [4]int{18, 22, 25, 30}

// Jeito 2: declarar e preencher depois
var salarios [4]int
salarios[0] = 2500
salarios[1] = 3200
salarios[2] = 4100
salarios[3] = 3800

// Jeito 3: com elipsis (tamanho automático)
dados := [...]int{1, 2, 3, 4, 5}

Nota: em Go, arrays têm tamanho fixo - assim como em Java. Se você precisa de um tamanho dinâmico, o Go usa slices, que veremos num post à parte. É comum confundir os dois, então fica a observação. 🦆

Acessando e modificando

Use o índice entre colchetes. O primeiro elemento está no índice 0, o último em length - 1. 

int[] numeros = {10, 20, 30, 40, 50};

numeros[2] = 99; // agora: {10, 20, 99, 40, 50}

System.out.println(numeros[0]);        // 10
System.out.println(numeros[numeros.length - 1]); // 50 (último)

Percorrendo um array

O loop for é o melhor amigo do array:

Java:

int[] notas = {8, 7, 9, 6, 10};

// for tradicional (com índice)
for (int i = 0; i < notas.length; i++) {
    System.out.println("Nota " + i + ": " + notas[i]);
}

// for-each (mais limpo, sem índice)
int soma = 0;
for (int n : notas) {
    soma += n;
}
System.out.println("Média: " + (soma / notas.length));

Go:

notas := [5]int{8, 7, 9, 6, 10}

// for com range
for i, n := range notas {
    fmt.Printf("Nota %d: %d\n", i, n)
}

// sem índice
soma := 0
for _, n := range notas {
    soma += n
}
fmt.Println("Média:", soma/len(notas))

Cuidado: índice inválido!

Se você tentar acessar uma posição que não existe (notas[10] num array de 5 elementos), o Java lança uma exceção ArrayIndexOutOfBoundsException. Em Go, o programa entra em pânico (panic).

Sempre verifique se o índice está entre 0 e length - 1.

Arrays multidimensionais

Um array pode ter mais de uma dimensão. O caso mais comum é a matriz (tabela com linhas e colunas). 

// Matriz 3x3 em Java
int[][] matriz = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

System.out.println(matriz[0][1]); // 2 (linha 0, coluna 1)
System.out.println(matriz[2][2]); // 9 (linha 2, coluna 2)

// Percorrendo uma matriz
for (int i = 0; i < matriz.length; i++) {
    for (int j = 0; j < matriz[i].length; j++) {
        System.out.print(matriz[i][j] + " ");
    }
    System.out.println();
}
// Matriz 3x3 em Go
matriz := [3][3]int{
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9},
}

fmt.Println(matriz[0][1]) // 2

for i := 0; i < len(matriz); i++ {
    for j := 0; j < len(matriz[i]); j++ {
        fmt.Print(matriz[i][j], " ")
    }
    fmt.Println()
}
Exercícios

1. Maior e menor

Dado o array {12, 7, 25, 3, 19, 8}, escreva um programa que encontre e exiba o maior e o menor valor.

Mostrar sugestão 
int[] nums = {12, 7, 25, 3, 19, 8};
int maior = nums[0];
int menor = nums[0];

for (int n : nums) {
    if (n > maior) maior = n;
    if (n < menor) menor = n;
}

System.out.println("Maior: " + maior);
System.out.println("Menor: " + menor);

2. Inverter array

Dado um array de 5 elementos, inverta a ordem dos valores (o primeiro vira o último e vice-versa) sem usar um segundo array.

Mostrar sugestão 
int[] arr = {1, 2, 3, 4, 5};
int esq = 0, dir = arr.length - 1;

while (esq < dir) {
    int temp = arr[esq];
    arr[esq] = arr[dir];
    arr[dir] = temp;
    esq++;
    dir--;
}

System.out.println(Arrays.toString(arr)); // [5, 4, 3, 2, 1]

3. (Desafio) Matriz identidade

Crie uma matriz 5x5 que seja uma matriz identidade: todos os elementos são 0, exceto a diagonal principal (linha = coluna) que vale 1.

Mostrar sugestão 
int[][] identidade = new int[5][5];

for (int i = 0; i < 5; i++) {
    identidade[i][i] = 1;
}

// Exibindo
for (int i = 0; i < 5; i++) {
    for (int j = 0; j < 5; j++) {
        System.out.print(identidade[i][j] + " ");
    }
    System.out.println();
}

Array é simples, mas tem um limite: o tamanho é fixo. Mas arrays não servem só para números - no próximo post, vamos ver que strings também são uma estrutura de dados: um array de caracteres. 🦆

In the previous post, we saw what data structures are. Now let us dive into the first one - and probably the one you already use the most without noticing.

Of all data structures, the array is the simplest and most fundamental. If you understand arrays well, everything that comes next (lists, stacks, queues, matrices) gets easier.

What is an array?

An array is a collection of elements of the same type, stored in consecutive memory positions. Each position has an index (number) that starts at 0. 

// Visually:
//   [10] [20] [30] [40] [50]
//     0    1    2    3    4

int[] numbers = {10, 20, 30, 40, 50};
System.out.println(numbers[0]); // 10
System.out.println(numbers[2]); // 30
System.out.println(numbers[4]); // 50

Why arrays exist

Without arrays, you would need a variable for each value: 

int grade1 = 8;
int grade2 = 7;
int grade3 = 9;
int grade4 = 6;
int grade5 = 10;
// What if there were 500 grades?

With an array, you group everything into a single variable and access by index: 

int[] grades = {8, 7, 9, 6, 10};
System.out.println(grades[0]); // 8
System.out.println(grades.length); // 5

Declaring and initializing

Java:

// Way 1: declare and initialize right away
int[] ages = {18, 22, 25, 30};

// Way 2: declare the size and fill later
int[] salaries = new int[4];
salaries[0] = 2500;
salaries[1] = 3200;
salaries[2] = 4100;
salaries[3] = 3800;

// Way 3: with new and values
int[] data = new int[]{1, 2, 3, 4, 5};

Go:

// Way 1
ages := [4]int{18, 22, 25, 30}

// Way 2: declare and fill later
var salaries [4]int
salaries[0] = 2500
salaries[1] = 3200
salaries[2] = 4100
salaries[3] = 3800

// Way 3: with ellipsis (automatic size)
data := [...]int{1, 2, 3, 4, 5}

Note: in Go, arrays have fixed size - just like in Java. If you need a dynamic size, Go uses slices, which we will cover in a separate post. It is common to confuse them, so there is the heads up. 🦆

Accessing and modifying

Use the index inside brackets. The first element is at index 0, the last at length - 1. 

int[] numbers = {10, 20, 30, 40, 50};

numbers[2] = 99; // now: {10, 20, 99, 40, 50}

System.out.println(numbers[0]);                 // 10
System.out.println(numbers[numbers.length - 1]); // 50 (last)

Traversing an array

The for loop is the array best friend:

Java:

int[] grades = {8, 7, 9, 6, 10};

// traditional for (with index)
for (int i = 0; i < grades.length; i++) {
    System.out.println("Grade " + i + ": " + grades[i]);
}

// for-each (cleaner, no index)
int sum = 0;
for (int n : grades) {
    sum += n;
}
System.out.println("Average: " + (sum / grades.length));

Go:

grades := [5]int{8, 7, 9, 6, 10}

// for with range
for i, n := range grades {
    fmt.Printf("Grade %d: %d
", i, n)
}

// without index
sum := 0
for _, n := range grades {
    sum += n
}
fmt.Println("Average:", sum/len(grades))

Warning: invalid index!

If you try to access a position that does not exist (grades[10] in a 5-element array), Java throws an ArrayIndexOutOfBoundsException. In Go, the program panics.

Always check that the index is between 0 and length - 1.

Multidimensional arrays

An array can have more than one dimension. The most common case is a matrix (table with rows and columns). 

// 3x3 matrix in Java
int[][] matrix = {
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9}
};

System.out.println(matrix[0][1]); // 2 (row 0, column 1)
System.out.println(matrix[2][2]); // 9 (row 2, column 2)

// Traversing a matrix
for (int i = 0; i < matrix.length; i++) {
    for (int j = 0; j < matrix[i].length; j++) {
        System.out.print(matrix[i][j] + " ");
    }
    System.out.println();
}
// 3x3 matrix in Go
matrix := [3][3]int{
    {1, 2, 3},
    {4, 5, 6},
    {7, 8, 9},
}

fmt.Println(matrix[0][1]) // 2

for i := 0; i < len(matrix); i++ {
    for j := 0; j < len(matrix[i]); j++ {
        fmt.Print(matrix[i][j], " ")
    }
    fmt.Println()
}
Exercises

1. Max and min

Given the array {12, 7, 25, 3, 19, 8}, write a program that finds and prints the largest and smallest value.

Show solution 
int[] nums = {12, 7, 25, 3, 19, 8};
int max = nums[0];
int min = nums[0];

for (int n : nums) {
    if (n > max) max = n;
    if (n < min) min = n;
}

System.out.println("Max: " + max);
System.out.println("Min: " + min);

2. Reverse an array

Given a 5-element array, reverse the order of values (first becomes last and vice versa) without using a second array.

Show solution 
int[] arr = {1, 2, 3, 4, 5};
int left = 0, right = arr.length - 1;

while (left < right) {
    int temp = arr[left];
    arr[left] = arr[right];
    arr[right] = temp;
    left++;
    right--;
}

System.out.println(Arrays.toString(arr)); // [5, 4, 3, 2, 1]

3. (Challenge) Identity matrix

Create a 5x5 matrix that is an identity matrix: all elements are 0, except the main diagonal (row = column) which is 1.

Show solution 
int[][] identity = new int[5][5];

for (int i = 0; i < 5; i++) {
    identity[i][i] = 1;
}

// Displaying
for (int i = 0; i < 5; i++) {
    for (int j = 0; j < 5; j++) {
        System.out.print(identity[i][j] + " ");
    }
    System.out.println();
}
