Duck To Basics

Strings: mais do que texto

Se você já programou, já usou strings. Toda linguagem tem. Mas pouca gente para pra pensar: o que é uma String, afinal?

String é um array de caracteres

Internamente, uma String é um array de caracteres (char[]) com métodos práticos pra manipular esse array. 

String nome = "duck";
// Internamente: ['d', 'u', 'c', 'k']
//                 0    1    2    3

Tudo que você aprendeu sobre arrays se aplica: cada caractere tem um índice, começa em 0, e você pode acessar posições individuais.

Acessando caracteres

Java:

String nome = "Maria";
System.out.println(nome.charAt(0)); // 'M'
System.out.println(nome.charAt(2)); // 'r'
System.out.println(nome.length());  // 5

Go:

nome := "Maria"
fmt.Println(string(nome[0])) // "M"
fmt.Println(string(nome[2])) // "r"
fmt.Println(len(nome))       // 5

Em Go, nome[i] retorna um byte, não um string. Por isso usamos string(nome[i]) pra converter. E o len() conta bytes, não caracteres - isso faz diferença com acentos e emojis.

Imutabilidade

Em Java, strings são imutáveis. Uma vez criada, uma String nunca muda. Qualquer operação que parece "modificar" a string na verdade cria uma nova. 

String s = "pato";
s.toUpperCase();        // cria "PATO", mas s ainda é "pato"
System.out.println(s);  // "pato"

s = s.toUpperCase();    // agora s aponta pra "PATO"
System.out.println(s);  // "PATO"

Em Go, strings também são imutáveis. Você não pode fazer nome[0] = 'X'. Precisa converter pra []rune se quiser modificar.

Principais operações com strings

Java:

String s = "Olá, Duck Society!";

// Tamanho
s.length();                        // 18

// Parte da string
s.substring(5, 9);                 // "Duck"

// Maiúsculo / minúsculo
s.toUpperCase();                   // "OLÁ, DUCK SOCIETY!"
s.toLowerCase();                   // "olá, duck society!"

// Verificar se contém
s.contains("Duck");                // true
s.startsWith("Olá");               // true
s.endsWith("!");                   // true

// Substituir
s.replace("Duck", "Pato");         // "Olá, Pato Society!"

// Dividir
String[] partes = s.split(", ");   // ["Olá", "Duck Society!"]

// Comparar (NUNCA use == com strings!)
s.equals("Olá, Duck Society!");    // true

Go (pacote strings):

s := "Olá, Duck Society!"
pacote := strings

// Tamanho
len(s)                             // 18 (em bytes)

// Parte da string
s[5:9]                             // "Duck"

// Maiúsculo / minúsculo
strings.ToUpper(s)                 // "OLÁ, DUCK SOCIETY!"
strings.ToLower(s)                 // "olá, duck society!"

// Verificar se contém
strings.Contains(s, "Duck")        // true
strings.HasPrefix(s, "Olá")        // true
strings.HasSuffix(s, "!")          // true

// Substituir
strings.Replace(s, "Duck", "Pato", 1) // "Olá, Pato Society!"

// Dividir
strings.Split(s, ", ")             // ["Olá", "Duck Society!"]

Percorrendo caracteres

Java:

String palavra = "algoritmo";
for (int i = 0; i < palavra.length(); i++) {
    System.out.println(palavra.charAt(i));
}

// Ou com for-each (requer converter pra char[])
for (char c : palavra.toCharArray()) {
    System.out.println(c);
}

Go (com range - percorre caracteres Unicode corretamente):

palavra := "algoritmo"
for i, c := range palavra {
    fmt.Printf("Índice %d: %c\n", i, c)
}

// Se quiser só o caractere, sem o índice:
for _, c := range palavra {
    fmt.Printf("%c ", c)
}

String vs StringBuilder (Java)

Como strings são imutáveis, concatenar muitas strings em um loop é ineficiente - cada + cria um novo objeto. 

// INEFICIENTE: cria várias strings intermediárias
String resultado = "";
for (int i = 0; i < 1000; i++) {
    resultado += i + ", ";
}

// EFICIENTE: StringBuilder modifica um buffer só
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i).append(", ");
}
String resultado = sb.toString();

Em Go, use strings.Builder que faz a mesma coisa.

2. Palíndromo (com strings)

Relembrando o exercício do módulo 1: verifique se uma string é um palíndromo (lê-se igual de trás pra frente). Use os métodos de string que vimos.

Mostrar sugestão 
public static boolean ehPalindromo(String s) {
    s = s.toLowerCase().replace(" ", "");
    int esq = 0, dir = s.length() - 1;

    while (esq < dir) {
        if (s.charAt(esq) != s.charAt(dir)) {
            return false;
        }
        esq++;
        dir--;
    }
    return true;
}

System.out.println(ehPalindromo("arara"));        // true
System.out.println(ehPalindromo("A torre da derrota")); // true (ignora espaços)

3. (Desafio) Cifra de César

Implemente uma cifra de César: desloque cada letra de uma string em N posições no alfabeto. Ex: com deslocamento 3, "abc" vira "def". Preserve maiúsculas e minúsculas, e ignore caracteres que não são letras.

Mostrar sugestão 
public static String cifrar(String texto, int deslocamento) {
    StringBuilder sb = new StringBuilder();

    for (int i = 0; i < texto.length(); i++) {
        char c = texto.charAt(i);

        if (c >= 'a' && c <= 'z') {
            c = (char) ((c - 'a' + deslocamento) % 26 + 'a');
        } else if (c >= 'A' && c <= 'Z') {
            c = (char) ((c - 'A' + deslocamento) % 26 + 'A');
        }

        sb.append(c);
    }
    return sb.toString();
}

System.out.println(cifrar("abc", 3));   // "def"
System.out.println(cifrar("xyz", 3));   // "abc"
System.out.println(cifrar("Duck!", 5)); // "Izhp!"

If you have ever programmed, you have used strings. Every language has them. But few people stop to think: what is a String, really?

String is an array of characters

Internally, a String is a character array (char[]) with convenient methods to manipulate that array. 

String name = "duck";
// Internally: ['d', 'u', 'c', 'k']
//                 0    1    2    3

Everything you learned about arrays applies: each character has an index, starts at 0, and you can access individual positions.

Accessing characters

Java:

String name = "Maria";
System.out.println(name.charAt(0)); // 'M'
System.out.println(name.charAt(2)); // 'r'
System.out.println(name.length());  // 5

Go:

name := "Maria"
fmt.Println(string(name[0])) // "M"
fmt.Println(string(name[2])) // "r"
fmt.Println(len(name))       // 5

In Go, name[i] returns a byte, not a string. That is why we use string(name[i]) to convert it. And len() counts bytes, not characters - this makes a difference with accents and emojis.

Immutability

In Java, strings are immutable. Once created, a String never changes. Any operation that seems to "modify" the string actually creates a new one. 

String s = "duck";
s.toUpperCase();        // creates "DUCK", but s is still "duck"
System.out.println(s);  // "duck"

s = s.toUpperCase();    // now s points to "DUCK"
System.out.println(s);  // "DUCK"

In Go, strings are also immutable. You cannot do name[0] = 'X'. You need to convert to []rune if you want to modify it.

Main string operations

Java:

String s = "Hello, Duck Society!";

// Length
s.length();                        // 22

// Substring
s.substring(7, 11);                // "Duck"

// Case
s.toUpperCase();                   // "HELLO, DUCK SOCIETY!"
s.toLowerCase();                   // "hello, duck society!"

// Check content
s.contains("Duck");                // true
s.startsWith("Hello");             // true
s.endsWith("!");                   // true

// Replace
s.replace("Duck", "Goose");        // "Hello, Goose Society!"

// Split
String[] parts = s.split(", ");    // ["Hello", "Duck Society!"]

// Compare (NEVER use == with strings!)
s.equals("Hello, Duck Society!");  // true

Go (package strings):

s := "Hello, Duck Society!"
pkg := strings

// Length
len(s)                             // 22 (in bytes)

// Substring
s[7:11]                            // "Duck"

// Case
strings.ToUpper(s)                 // "HELLO, DUCK SOCIETY!"
strings.ToLower(s)                 // "hello, duck society!"

// Check content
strings.Contains(s, "Duck")        // true
strings.HasPrefix(s, "Hello")      // true
strings.HasSuffix(s, "!")          // true

// Replace
strings.Replace(s, "Duck", "Goose", 1) // "Hello, Goose Society!"

// Split
strings.Split(s, ", ")             // ["Hello", "Duck Society!"]

Traversing characters

Java:

String word = "algorithm";
for (int i = 0; i < word.length(); i++) {
    System.out.println(word.charAt(i));
}

// Or with for-each (requires converting to char[])
for (char c : word.toCharArray()) {
    System.out.println(c);
}

Go (with range - traverses Unicode correctly):

word := "algorithm"
for i, c := range word {
    fmt.Printf("Index %d: %c
", i, c)
}

// If you just want the character, without the index:
for _, c := range word {
    fmt.Printf("%c ", c)
}

String vs StringBuilder (Java)

Since strings are immutable, concatenating many strings in a loop is inefficient - each + creates a new object. 

// INEFFICIENT: creates many intermediate strings
String result = "";
for (int i = 0; i < 1000; i++) {
    result += i + ", ";
}

// EFFICIENT: StringBuilder modifies a single buffer
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i).append(", ");
}
String result = sb.toString();

In Go, use strings.Builder which does the same thing.

2. Palindrome (with strings)

Remembering the exercise from module 1: check if a string is a palindrome (reads the same backwards). Use the string methods we have seen.

Show solution 
public static boolean isPalindrome(String s) {
    s = s.toLowerCase().replace(" ", "");
    int left = 0, right = s.length() - 1;

    while (left < right) {
        if (s.charAt(left) != s.charAt(right)) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}

System.out.println(isPalindrome("racecar"));        // true
System.out.println(isPalindrome("A man a plan a canal")); // true (ignores spaces)

3. (Challenge) Caesar cipher

Implement a Caesar cipher: shift each letter of a string by N positions in the alphabet. Ex: with shift 3, "abc" becomes "def". Preserve uppercase and lowercase, and ignore non-letter characters.

Show solution 
public static String cipher(String text, int shift) {
    StringBuilder sb = new StringBuilder();

    for (int i = 0; i < text.length(); i++) {
        char c = text.charAt(i);

        if (c >= 'a' && c <= 'z') {
            c = (char) ((c - 'a' + shift) % 26 + 'a');
        } else if (c >= 'A' && c <= 'Z') {
            c = (char) ((c - 'A' + shift) % 26 + 'A');
        }

        sb.append(c);
    }
    return sb.toString();
}

System.out.println(cipher("abc", 3));   // "def"
System.out.println(cipher("xyz", 3));   // "abc"
System.out.println(cipher("Duck!", 5)); // "Izhp!"
